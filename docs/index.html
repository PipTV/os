Three steps. One remote.

All on the TV. No computer, no cables.

piptv.github.io

Step 1

On your TV, open Google Play and install Downloader.

Step 2

Open it and type piptv.github.io.

Step 3

Press OK on Install free, then Install.

To remove Pip, uninstall Pip OS in Settings → Apps; it doesn't change your TV's system. With a computer: adb install pip-tv.apk. Android phone remote: pip-remote.apk. On iPhone, use the web remote the TV shows for now.
